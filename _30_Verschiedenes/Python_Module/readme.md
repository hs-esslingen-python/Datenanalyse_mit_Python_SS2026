# Zugriff auf eigene Python Pakete und Module von einem Jupyter Notebook


### Start 
+ Jupyter Notebook _Mein_Jupyter_Notebook.ipynb_ auswählen
+ Python Skript _Mein_Python_Skript.py_

### Ordnerstruktur

```
\Paket1 - Paket 1
    \__init__.py  - Kennzeichnung als Python Paket
    \Modul1_im_Paket1.py - Modul 1 im Paket 1
\Paket2 - Paket 2
    \__init__.py  - Kennzeichnung als Python Paket
    \Modul1.py - Modul 1 im Paket 2
    \Modul2.py - Modul 2 im Paket 2
\Modul1.py - Modul ohne eigenes Paket

```
